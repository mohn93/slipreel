## 0.1.0

* Initial release of Windows platform plugin
* Implement Graphics Capture API for screen and window capture
* Window enumeration via Win32 API
* Screen/display enumeration with monitor info
* Frame streaming with BGRA format
* D3D11 texture capture and conversion
* Real-time frame capture at configurable FPS
* Support for Windows 10 1803+ (Build 17134)
* Integration with screen_recorder_platform_interface
